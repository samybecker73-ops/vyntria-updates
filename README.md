# VYNTRIA Updates

Dépôt public destiné aux publications officielles et aux informations de mise à jour de VYNTRIA.

## Rôle de ce dépôt

- Présenter les versions publiées et leurs notes de version.
- Héberger les installateurs et archives en tant qu'assets de GitHub Releases.
- Fournir les métadonnées nécessaires au mécanisme de mise à jour de l'application.

## Publication

Chaque version publiée doit être vérifiée avant mise en ligne. Les fichiers de distribution seront joints à une GitHub Release identifiée par un tag de version (par exemple `v1.0.0`).

Le fichier `latest.example.json` est uniquement un exemple de contrat de données. Il ne doit pas être utilisé par l'application avant validation de son format avec le code du programme de mise à jour.

## Sécurité

Aucun secret, jeton, clé privée, donnée utilisateur ou code source privé ne doit être publié ici.

Aucune automatisation GitHub Actions n'est configurée à ce stade. Les premières publications seront préparées et contrôlées manuellement.
